## 🌿 Highlights & Architecture

- **Living Atmospheric Meadow Canvas**: Dynamic multi-phase sky with real-time lighting changes, drifting clouds, fluttering flower petals, multi-species butterflies, and layered rolling meadow terrain.
- **Botanical Flower Cursor & Falling Bloom Trail**: Custom 5-petal interactive cursor that blooms on hover, and leaves suspended botanical flowers (Sakura, Marigold, Cosmos, Daisy, Lavender, Peach) that float for ~300ms before fluttering down to the meadow ground.
- **Acoustic Physical Kalimba Audio Engine**: Handcrafted procedural physical synthesis using Web Audio API tines, delivering calming, charming pentatonic melodies with organic breathing pauses.
- **Bespoke Botanical Minimal Dock & Navigation**: Fluid, responsive navigation with full desktop dock and a mobile 3-dots drawer menu.
- **Embedded Interactive System Terminal (CLI)**: Full keyboard-driven terminal emulator with command history, autocomplete, sound synthesis, and real-time portfolio exploration.
- **Pure Web Craft**: Built entirely with Vanilla HTML5, Modern CSS3, and JavaScript — 0 external heavy frameworks, zero runtime bloat, 60fps GPU acceleration.
